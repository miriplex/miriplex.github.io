Professional work · December 2024–May 2026

AI lesson insights at VirtuosoHub

Helping music students retain useful information from online lessons without having to take extensive notes themselves.

  • LiveKit AI agents
  • Transcription evaluation
  • Structured outputs
  • K3s
  • Grafana

From a conversation to something a student can use

VirtuosoHub is a videoconferencing product for musicians. The lesson-assistance workflow connected agents to conference audio, collected transcripts and used that text to produce post-call summaries and lesson insights.

I worked as Project Manager with backend engineering and DevOps responsibilities. The LiveKit AI agents already existed when I was assigned to help finish and improve them.

  1. 01Lesson audio
  2. 02Transcript collection
  3. 03Post-call structured insights
  4. 04Strengths & practice priorities

My contribution

  • Refined transcript collection. I changed how existing LiveKit AI agents collected the text used by the downstream lesson workflow.
  • Compared transcription models. I evaluated alternatives on a test bench for our application, then integrated the selected model into the agent.
  • Designed useful outputs. I created prompts and a structure for lesson insights, so a dynamic interface could show what the learner had done well, where they could improve and what to practise.

The feedback was based on the collected transcript, connecting the information from the lesson to an organised set of next steps for the student.

The supporting engineering

I also worked on a WebRTC signalling prototype and its move to LiveKit, an AWS S3-backed sheet-music library, and deployment infrastructure. I supported three LiveKit agent nodes and two backend nodes on Hetzner using K3s, with Grafana monitoring.

That combination mattered: the transcript and insights were useful only if the surrounding call, data collection and backend workflow worked together.

What this taught me

For an AI feature, the useful output is not simply “some generated text”. The student needed a clear record of the lesson and practical next steps. Designing the output structure alongside the transcript workflow connected the engineering decisions to that purpose.

This case study describes my contribution to a team product. It does not reproduce internal source code or student lesson data.
