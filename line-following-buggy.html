Line-following buggy

Designing and tuning the team’s C++ PID controller for a timed line-following run.

  • C++
  • PID control

My contribution

I designed and tuned the line-following controller. The work centred on balancing a fast response to changes in the line with stable steering, then checking the behaviour on the buggy.

The vehicle was a team project; my contribution highlighted here is the controller software and tuning.

The result

6th of 50The team’s placing by speed, with the run completed without line-following errors.

This is a compact example of applying C++ and feedback control to a physical system, where a useful result depends on both implementation and practical tuning.
